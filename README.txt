PREVIEW
Open index.html in a browser. Open designflow/index.html to test the interactive prototype.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository, for example keerthana-ather-portfolio.
2. Upload the contents of this folder (including designflow/ and resume.pdf) to the repository root.
3. Go to Settings > Pages. Choose Deploy from a branch, main, /(root), and Save.
4. Wait for the deployment URL, then test the site and the DesignFlow link on desktop/mobile.
